# Recording the switching demo

1. Install this checkout as `CodeTestSwitcher` in Sublime Text's `Packages` folder.
2. Open `examples/demo.sublime-project` and `examples/calculator.py`.
3. Capture the editor window with the source file active.
4. Press Command+. (macOS) or Ctrl+. (Windows/Linux) and capture the test file.
5. Press the shortcut again and capture the source file.
6. Combine the source and test captures into a looping GIF, holding each for
   about two seconds, and save it as `docs/switching.gif`.

Keep the project sidebar and filenames visible so the relationship is clear.
Use only the example project in the recording; exclude consoles and personal files.
